# UNIVERSALIS-OS

The public, open-source operating-system edition of UNIVERSALIS. UNIVERSALIS-OS and C2O-OS are the public, open-source and private-source editions of the same underlying operating-system architecture. UNIVERSALIS-App and C2O-App are the corresponding application editions.

UNIVERSALIS is designed to remain independently operable through its public architecture and contracts.

## Alchemy Taxonomies

This repository is part of the shared four-repository collection of 33 dedicated Alchemy Taxonomy workspaces. Browse the [Alchemy Taxonomies](./Alchemy%20Taxonomies/) collection.

The [Alchemy Taxonomy for the Universal Subjects of Knowledge](./Alchemy%20Taxonomies/Alchemy%20Taxonomy%20for%20the%20Universal%20Subjects%20of%20Knowledge/ALCHEMY_TAXONOMY_FOR_THE_UNIVERSAL_SUBJECTS_OF_KNOWLEDGE.md) establishes 22 C2O and UNIVERSALIS contexts and the rules for defining, relating, and validating Alchemy classifications. A context is an application setting for the taxonomy, not automatically a separate system or classification. Its 72 versioned cross-domain relationship evidence assessments (`v0.1.0` through `v0.72.0`) are preserved alongside it. The shared taxonomy file contains no private C2O implementation details.
